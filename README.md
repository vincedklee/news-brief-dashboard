# news-brief-dashboard

뉴스 브리핑 대시보드를 GitHub Pages로 서비스하기 위한 **배포 전용** 저장소입니다.

- 보는 곳: https://vincedklee.github.io/news-brief-dashboard/
- 이 저장소의 `index.html`은 **자동 생성됩니다.** 직접 고치지 마세요
- 원본과 생성 스크립트는 비공개 저장소 `vincedklee/news-brief`에 있습니다
  (`dashboard.html` · `tools/build_pages.py`)

매일 아침 브리핑이 원본 저장소 `main`에 올라오면 GitHub Actions가 페이지를 다시 만들어
여기에 밀어 넣습니다.
